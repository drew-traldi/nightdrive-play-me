# 🌆 Nightdrive

A playable synthwave piano with oscilloscope, chorus and echo. Record your jam and download it.

**▶ Use it here: [https://drew-traldi.github.io/nightdrive-play-me/](https://drew-traldi.github.io/nightdrive-play-me/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
